Create src/store/types/investment.types.ts with the following interfaces following the I-prefix naming convention:

- IETFTransaction: Represents a single ETF buy or sell record
  - id: string (crypto.randomUUID())
  - date: string (YYYY-MM-DD format, same as ITransaction)
  - ticker: string (e.g., "SWDA.MI", stored as uppercase)
  - description: string
  - type: 'buy' | 'sell'
  - units: number (positive, decimal for fractional ETF shares)
  - price: number (price per unit in EUR, positive)
  - totalAmount: number (units * price, positive; stored for audit trail)
  - accountId: string (matches broker account id)
  - notes?: string (optional user note)

- IPortfolioSnapshot: Time-series record for portfolio value charting
  - id: string
  - date: string (YYYY-MM-DD)
  - totalInvested: number (sum of all purchase amounts, cost basis)
  - currentValue: number (total ETF units * current market price)
  - cashBalance: number (uninvested broker cash)
  - accruedInterest: number (accumulated interest on cash)
  - holdings: IInvestmentHolding[] (per-ETF breakdown)

- IBrokerConfig: User-configurable broker parameters
  - brokerName: string (default "Trade Republic")
  - lumpSumAmount: number (one-time initial investment, default 0)
  - monthlyPacAmount: number (monthly PAC contribution, default 0)
  - ticker: string (ETF ticker symbol, default "SWDA.MI")
  - interestRate: number (APY on uninvested cash as percentage, default 0)

- IInvestmentHolding: Per-ETF holdings breakdown within a snapshot
  - ticker: string
  - units: number
  - avgCost: number (Prezzo Medio di Carico = totalCost / totalUnits)
  - currentPrice: number
  - value: number (units * currentPrice)
  - returnPercent: number ((value - units * avgCost) / (units * avgCost) * 100)

- IPortfolioPoint: Line chart data point (add to this file, also usable by analytics)
  - date: string (YYYY-MM format for monthly chart points)
  - value: number (total portfolio value at that point)
  - invested: number (total invested cost basis at that point)

All interfaces use the I-prefix naming convention matching existing finance.types.ts.
Use TypeScript union types for the transaction type field: type: 'buy' | 'sell'.
Make all optional fields use the ?: syntax for nullable fields (notes?).
Export all interfaces with named exports.
