# OpenCode Prompt: System Settings Page Redesign (React + MUI v9)

## Context & Objective
We are implementing the complete redesign of the **Balancr** System Settings page (`SettingsPage.tsx`).
A high-fidelity design prototype has been approved in Google Stitch (`Screenshot_2026-10-26_alle_16.48.26.png`). The reference screenshots of existing settings features are available in the repository/sources (`Settings_1.png` through `Settings_8.png`).

Your goal is to reproduce this approved Stitch prototype in our React + Material UI (MUI v9) codebase with **95%+ visual and functional fidelity**, maintaining strict compatibility with our existing Zustand state management, Firebase sync, and Day.js date handling.

---

## Technical Specifications & Design System Standards

1. **Strict MUI v9 & Theme Token Adherence**:
   - Primary Packages: `@mui/material` (`^9.0.1`), `@mui/icons-material` (`^9.0.1`), `@mui/x-date-pickers` (`^9.2.0`), `@mui/x-charts` (`^9.2.0`).
   - **Background**: Deep Slate (`#0B0E14`).
   - **Card / Surface**: Solid Dark Slate (`#131B2E`) with a 1px solid subtle border (`#1E293B` or `#334155`).
   - **NO White Input Boxes or Bright Hover Outlines**: All inputs, selects, and textfields must use dark backgrounds (`#0B0E14` or `#1A233A`), light text, and subtle focus borders (`#0EA5E9`).
   - **Typography**: Clean Sans-Serif (`Inter`) for labels and headers; **Monospaced Font (`JetBrains Mono`)** for ALL numerical values, currency symbols (`€`), initial account balances, date formats (`01/01/2026`), and percentage rates (`%`).

2. **Layout Architecture: Sub-Sidebar Navigation ("Parametri Sistema")**:
   - Reuse the top shell / topbar from `components/layout/Layout.tsx`.
   - Page Header: "IMPOSTAZIONI SISTEMA" + subtitle "Configurazione parametri mastro, moduli e preferenze regionali".
   - **Desktop Layout (`≥ md` screens)**:
     - 2-Column layout: Sub-Sidebar navigation on the left (~240px wide) + Active Tab Panel on the right (flex 1).
     - **Sub-Sidebar Tabs (7 Sections)**:
       1. ⚙️ **Generali & Preferenze** (Language, Currency, Module Toggles, Danger Zone)
       2. 🏦 **Conti & Carte** (Checking Accounts, Credit/Debit Cards, Brokerage Accounts, Calculation Start Date) - *Badge: Active Count*
       3. 🏷️ **Categorie Spese** (Expense categories & subcategories hierarchy) - *Badge: Total Count*
       4. 💰 **Categorie Entrate** (Income categories & subcategories hierarchy) - *Badge: Total Count*
       5. 🔄 **Spese Ricorrenti** (Recurring templates, billing frequency, monthly/annual amortised totals) - *Badge: Active Count*
       6. 📈 **Proiezioni & Tassi** (Inflation Rate %, Tax Rate % for wealth projections)
       7. 💾 **Backup & Ripristino** (JSON export/import, disaster recovery)
   - **Mobile Responsiveness (`< md` screens)**:
     - Convert the left Sub-Sidebar into a horizontal scrollable pill bar (`Tabs` with `variant="scrollable"`) at the top of the settings page.

3. **Slide-Over Drawer for Entity Creation/Edits**:
   - All "+ Add" actions (`+ Nuovo Conto`, `+ Nuova Carta`, `+ Nuova Categoria`, `+ Nuovo Template Ricorrente`) MUST trigger a **Right Slide-Over Drawer** (480px width on desktop, 100vw on mobile), reusing the exact design and UX pattern established in `AddTransactionDrawer.tsx`.

4. **Detailed Feature Mapping Across Tabs**:

   - **Tab 1: Generali & Preferenze**:
     - *Regional Settings*: Language selector (`IT` / `EN`), Primary Currency selector (`EUR (€)`), Date Format preview (`DD/MM/YYYY`).
     - *Active App Modules*: Toggle switches for `Flotta Auto`, `Utenze & Consumi`, `Investimenti & PAC ETF`, `Budgeting`.
     - *Danger Zone*: Red-bordered warning card for account deletion / data reset with confirmation modal.

   - **Tab 2: Conti & Carte**:
     - *Checking & Brokerage Accounts*: Cards displaying account name, IBAN/Broker, Initial Balance (monospaced), and active card links.
     - *Credit / Debit Cards*: Linked card cards displaying Card Name, Plafond Limit, Monthly Reset Day, and linked account.
     - *Calculation Start Date*: DatePicker field defining the baseline date for balance calculations.

   - **Tab 3 & 4: Categorie Spese / Entrate**:
     - Nested card list showing categories and subcategories.
     - Color dot indicators + Category Icons + Drag-and-drop or re-order controls.
     - Inline Edit / Delete buttons + `+ Aggiungi Categoria` / `+ Aggiungi Sottocategoria`.

   - **Tab 5: Spese Ricorrenti**:
     - Dense list of recurring transaction templates.
     - Badges for frequency (`MENSILE` / `ANNUALE`), monthly equivalent cost in monospaced font, auto-charge date indicator, and linked account.

   - **Tab 6: Proiezioni & Tassi**:
     - Financial projection parameters: Inflation Rate (`%`), Tax Rate (`%`), Baseline Growth Rate (`%`).

   - **Tab 7: Backup & Ripristino**:
     - *Export*: Primary button "Scarica Backup JSON" with timestamped filename generation.
     - *Restore*: File dropzone / upload input for JSON restore with validation alert modal.
