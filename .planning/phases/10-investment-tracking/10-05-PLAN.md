Create src/analytics/hooks/usePortfolio.ts with:

Imports: useMemo from react, useInvestmentStore from store/useInvestmentStore, calcAccruedInterest from store/useInvestmentStore, dayjs

Export function usePortfolio():

Read from useInvestmentStore: etfTransactions, portfolioSnapshots, brokerConfig, currentPrice

Return a useMemo object with these computed values:

1. totalInvested (cost basis): Sum of all buy transactions' totalAmount minus sell transactions' totalAmount. Buy transactions add to cost basis; sell transactions reduce cost proportionally (matching the PMC formula from research).

2. totalUnits: Sum of all buy transaction units minus sell transaction units.

3. avgCost: totalInvested / totalUnits (if totalUnits > 0, else 0).

4. currentValue: totalUnits * (currentPrice ?? 0). If currentPrice is null, use the latest portfolioSnapshot.currentValue as fallback.

5. totalReturn: currentValue - totalInvested.

6. totalReturnPercent: totalInvested > 0 ? (totalReturn / totalInvested) * 100 : 0.

7. cashBalance: Read from brokerConfig (this represents uninvested cash). Note: in future this could come from a transfer-based calculation.

8. accruedInterest: calcAccruedInterest(cashBalance, brokerConfig.interestRate).

9. chartData: Map portfolioSnapshots to IPortfolioPoint[] format: { date: s.date, value: s.currentValue, invested: s.totalInvested }. Sort by date ascending.

10. holdings: Aggregate current holdings by ticker from etfTransactions. For each ticker, sum units (buys - sells), calculate avgCost (totalCostOfBuys - proportionalCostOfSells) / units. This follows the PMC formula from research.

11. isPositive: currentValue >= totalInvested (boolean for coloring).
