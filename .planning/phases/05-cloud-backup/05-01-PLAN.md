   ```typescript
   let gapiLoaded = false;
   let gapiInitialized = false;

   export async function loadGapiClient(): Promise<void> {
     if (gapiLoaded) return;
     
     return new Promise((resolve, reject) => {
       const script = document.createElement('script');
       script.src = 'https://apis.google.com/js/api.js';
       script.onload = () => {
         gapiLoaded = true;
         (window as any).gapi.load('client:auth2', async () => {
           try {
             await (window as any).gapi.client.init({
               clientId: getEnvVar('VITE_GOOGLE_CLIENT_ID'),
               discoveryDocs: ['https://www.googleapis.com/discovery/v1/apis/drive/v3/rest'],
               scope: 'https://www.googleapis.com/auth/drive.file'
             });
             gapiInitialized = true;
             resolve();
           } catch (err) {
             reject(err);
           }
         });
       };
       script.onerror = reject;
       document.body.appendChild(script);
     });
   }
   ```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| app → Google Drive API | OAuth token sent to Drive API |
| local → cloud | Backup data leaves user's device |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-01 | Tampering | Upload modifies wrong Drive file | mitigate | Create new file each time, don't update existing |
| T-05-02 | Denial of Service | Drive API quota exceeded | accept | User notified, local download still works |
| T-05-03 | Information Disclosure | Access token leaked | mitigate | Use short-lived tokens, limited scope (drive.file) |
| T-05-04 | Elevation of Privilege | Token used for other Drive operations | mitigate | Request minimal scope (drive.file only) |
</threat_model>
