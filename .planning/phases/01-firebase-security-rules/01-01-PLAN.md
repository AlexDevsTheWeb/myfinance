  <action>
Create firestore.rules in project root with user data isolation rules:

```javascript
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    // Helper function: is the user authenticated?
    function isSignedIn() {
      return request.auth != null;
    }

    // Helper function: does the user own this document?
    function isOwner(userId) {
      return isSignedIn() && request.auth.uid == userId;
    }

    // User documents: only the authenticated owner can read/write their data
    match /users/{userId} {
      allow read: if isOwner(userId);
      allow write: if isOwner(userId);
    }
  }
}
```

Then update firebase.json to explicitly include the firestore rules configuration:

Add to firebase.json (after the hosting block):
```json
"firestore": {
  "rules": "firestore.rules"
},
```

Then deploy the rules to Firebase:
```bash
firebase deploy --only firestore:rules --project myfinancetracker-b257e
```

Note: If Firebase CLI not logged in, use `firebase login` first, then deploy.
